Component storage table

A base fixed to the table carries four square modules: one each for pin spacing 1, 2 and 4 (2.54, 5.08 and 10.16 mm) and one that cradles the RJ45 grip. Each module stands on four toes in sockets, so it always lands in the same place. The Hand-E picks every part with the same fingertips and wrist orientation, at the same height; only x and y change.

The base and the four modules are the actual STLs; module STLs lie plate-top-down for printing and are turned back here. Parts, the Hand-E, plug and cable are reference shapes for checking clearance; the fingertips are the 24 × 8 mm ones the RJ45 grip was made for. Poses are in the base frame: origin at the front-left corner of the base top, x along the front edge, z up. The tip bottom is the pick point. The particles are for show only.
